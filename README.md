# Water Rocket Simulation

A python simulation for modelling water rocket flight parameters from initial conditions

The simulation reproduces key features of the water rocket flight path, including:
- apogee height
- time to reach apogee
- water burnout time
- air burnout time
- total flight time
- landing speed
- max speed
- max thrust
- max acceleration
